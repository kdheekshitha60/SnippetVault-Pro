# SnippetVault Pro

### Next-Gen Intelligent Media Ledger Matrix & Workspace Dashboard
Built exclusively as a solo student entry for the **RevenueCat Shipaton 2026**.

## 🚀 Concept Overview
SnippetVault Pro is a hyper-fast layout engine built for mobile creators, social managers, and influencers. It aggregates essential brand registries, secure credential vault storage keys, and cloud data vectors into a zero-lag unified matrix. 

## 🛠️ Technical Architecture & Features
- **State-Machine Lifecycle Controller:** Structured fluid routing (`SPLASH` -> `LOGIN` -> `CINEMATIC_WELCOME` -> `DASHBOARD`) using `AnimatedSwitcher` transitions.
- **Persistent State Cache Engine:** Integrated `SharedPreferences` framework ensuring zero data loss upon application process execution resets.
- **CORS-Immune UI Vector Matrix:** Engineered with localized vector elements to secure the UI layer from web asset rendering errors.
- **Dynamic RevenueCat Paywall Integration:** Native implementation of a sandbox premium ledger track gate that intercepts workflows dynamically at user limits.

## 📱 Targets & Framework
- Built entirely using **Flutter (Dart)** for cross-platform compliance (Android, iOS, Web targets).
